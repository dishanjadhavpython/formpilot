Create your vault

Pick a passphrase. It encrypts everything you store here (AES-256-GCM, key derived with PBKDF2). It is never saved anywhere — which means nobody, including this extension, can recover your data if you forget it.

Longer is stronger. A few random words beats one clever word.

Read an ID image

Recognises text on a PAN card, Aadhaar or marksheet and suggests values for your fields. The engine, its WebAssembly core and the English language data all ship inside this extension — nothing is uploaded, and it works offline. The first run loads about 7 MB from local disk and takes a few seconds.

Backup

      

        The backup file is the encrypted vault, byte for byte — the same
        ciphertext that sits in storage. It can only be opened with the passphrase
        that was in force when you exported it. Keep it somewhere you control.
      


      

        
        
      


      
Restore

      

        Importing replaces the vault on this device. You will need the
        passphrase that backup was made with — not your current one, if they differ.
