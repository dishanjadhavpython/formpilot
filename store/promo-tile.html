Capturing this

The box above is exactly 440×280, the size Chrome wants. Capture the element itself rather than a region, so nothing on this page bleeds in and no scaling softens the type:

  1. Right-click the tile → Inspect.
  2. In the Elements panel, right-click the <div id="tile"> node → Capture node screenshot.
  3. Confirm the saved PNG is 440×280 and upload it as-is.

The number is illustrative, so keep it honest: run a real photo through the image tool first and use whatever it actually produces.
